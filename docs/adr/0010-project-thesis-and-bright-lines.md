# 프로젝트 주장과 지키는 선

## 주장

AI 가 산업 현장에 못 들어가는 병목은 모델 성능이 아니라, "**어디까지 맡겨도 되는지**"를 증명할 방법이 없다는 것이다. 이 프로젝트는 그 증명을 재는 시험장이다.

리포트와 README 의 1문단 요약이 이 주장을 그대로 쓴다. 모델 성능 비교(정확도·추론 품질)는 2차 결과이고, 1차 결과는 **"정책 게이트의 유무가 자율성 판단의 비용·안전 지표를 유의미하게 바꾸는가"** 다.

## 지키는 선 세 가지

구현 단계에서 어떤 유혹이 와도 양보하지 않는 선.

1. **설비 정지는 항상 사람이 결정한다.** 에이전트가 `REQUEST_STOP` 을 내도 정책 게이트가 항상 사람 결정으로 변환한다. 이 규칙은 Hypothesis 퍼즈로 반례 0 을 증명한다.
2. **평가용 설비 30대는 끝날 때까지 보지 않는다.** LR 학습, 프롬프트 튜닝, 스캐폴딩 수정, 하드케이스 합성 전부 개발용 70대만 쓴다. 분할은 `data/splits.json` 에 커밋돼 있다 (ADR 0007).
3. **Azure 데이터는 재배포하지 않는다.** ADR 0001 에 따라 `data/`, VCR 캐시, 실행 로그, Azure 참조 시나리오 YAML 전부 커밋하지 않는다 (ADR 0008).

## 선택 실험 (여유 있을 때만)

기본 평가가 끝나고 리포트가 완성된 뒤에만 다음을 시도한다:

- **모델 2개 비교**: Llama 3.2 3B (로컬 폴백) 과 Muse Spark (Meta Model API) 로 **동일한 시험**을 돌려 "모델이 좋아지면 자율성 판단도 좋아지는가" 를 본다.
- 결과가 뒤집히든 아니든 리포트에 그대로 적는다. 자율성 축이 모델 축과 **분리**됐는지 확인하는 게 이 보조 실험의 핵심.

기본 평가가 끝나기 전에는 모델 비교에 시간을 쓰지 않는다. 솔로 1주일 안에 하네스 자체를 끝내는 게 우선.

## Consequences

- 리포트 서문과 README 서문에 "주장"을 그대로 인용한다.
- 세 선을 어긴 상태로 수치를 리포트에 넣지 않는다. 넣게 되면 그 사실을 명시한다.
- 모델 비교 결과는 메인 표가 아니라 리포트 부록으로.
