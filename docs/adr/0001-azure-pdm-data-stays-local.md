# Azure PdM 데이터는 `data/raw/`에만 두고 git에 올리지 않는다

사용하는 Microsoft Azure 예지정비 샘플 데이터는 시뮬레이션 데이터이며(Microsoft 공식 블로그, 2016-04-21), Kaggle 배포본의 라이선스는 unknown이다. 재배포 가능 여부를 알 수 없으므로 사용자가 Kaggle에서 직접 받아 `data/raw/`에 넣고, `data/`는 `.gitignore`로 제외해 저장소에 포함하지 않는다. README에는 "시뮬레이션 데이터, 라이선스 미표기, 재배포하지 않음"을 명시한다.

## Considered Options

- 저장소에 CSV를 커밋: 재현은 쉽지만 라이선스 불명 데이터를 재배포하게 되어 기각.

## Consequences

- 저장소만으로는 재현할 수 없다. 재현 절차(다운로드 출처, 파일 목록)를 README에 적어야 한다.
- `data/` 전체가 무시되므로, 데이터에서 파생한 시나리오·정답 파일도 `data/` 아래에 두면 커밋되지 않는다. 정답 규칙은 코드로, 시나리오 목록은 설비 ID·시점만 담은 파일로 `data/` 밖에 커밋해야 하는지는 이후에 정한다.
