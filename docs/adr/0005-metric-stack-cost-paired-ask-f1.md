# 리포트 메인 지표는 비용 총합, 쌍 정확도, Ask-F1, 적시 비율 네 축으로 간다

"정확도 하나"로는 자율성 판단을 공정하게 못 잰다. 네 축을 함께 보고 bootstrap 신뢰구간을 붙인다.

1. **비용 총합**: `config/cost.yaml` 의 가중치(놓친 고장 : 과잉 정지 : 과잉 에스컬 = 100 : 10 : 1, **가정값**)로 환산한 총 비용. 민감도 분석을 리포트 부록에 bootstrap 한 함수로 붙인다.
2. **쌍 정확도**: AgentAbstain(arXiv 2607.10059) 설계에서. 쌍 둘 다 맞혀야 1점.
3. **Ask-F1**: HiL-Bench(arXiv 2604.09408) 에서. 에스컬레이션 품질을 질문 정밀도와 blocker 재현율의 조화 평균으로.
4. **적시 비율**: act 짝 중 `적시` 안에 조치한 비율. 보조 지표. ADR 0006 참조.

보정(ECE/Brier)는 가볍게. 비용 가중치 100:10:1 은 **문헌에서 가져온 값이 아니라 가정**이라는 사실을 config 와 리포트에 명시한다.

## Considered Options

- **단일 비용 지표**: 가중치 조작으로 결론이 뒤집히는 걸 숨길 위험. 기각.
- **정확도만**: 자율성 축을 못 잰다. 기각.
- **PHMForge 스타일 과제 성공률**: 우리 축(언제 안 할지)을 못 잰다. 기각.

## Consequences

- 리포트 메인 표는 베이스라인 4개(always-ask, always-act, LR, 센서규칙+조회표) + 어블레이션 2개(LLM+툴, LLM+툴+게이트) 총 6행 × 네 축.
- 모든 비율에 bootstrap 신뢰구간을 붙인다. `src/mautonomy/metrics/bootstrap.py` 함수 하나.
